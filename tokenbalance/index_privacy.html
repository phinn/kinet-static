TokenBalance 隐私政策

TokenBalance · 最后更新：2026 年 11 月 · English below

一句话版本

TokenBalance 没有服务器，也不收集任何数据。无账号、无注册、无广告、无统计 SDK、无第三方追踪。你的 API Key 和余额数据只存在于你自己的设备上。

它做什么

TokenBalance 是一个本地看板，把你在各家 AI 服务商（如 DeepSeek、OpenAI、智谱、Kimi、MiniMax、阶跃星辰、OpenRouter 等）的账户余额、配额用量和消耗趋势汇总到一处显示。

你的数据

  • API Key / Token：保存在本机的 iOS 钥匙串（Keychain）中，不会上传到任何服务器，也不会同步到 iCloud。
  • 账户名称、分组、余额快照：保存在本机 App 的本地存储中。
  • 汇率设置：保存在本机偏好设置中。
  • 开发者无法访问上述任何数据。卸载 App 即全部删除。

网络请求

当你点击刷新（或开启自动刷新）时，App 会用你填写的 Key 直接向对应服务商的官方 API 发起请求，读取余额与用量。请求从你的设备直达服务商，不经过开发者或任何中间服务器。这些请求同时受对应服务商的隐私政策约束。

若你设置自定义汇率，App 会向公开汇率接口请求当前汇率，不携带任何身份信息。

权限说明

  • 通知：仅在你主动开启「配额告警」时用于发送本地通知。通知在本机生成，不经过推送服务器。
  • App 不申请通讯录、定位、相机、麦克风、健康、照片等任何敏感权限。

儿童

本 App 不面向 13 岁以下儿童，也不会有意收集其任何信息。

变更

若本政策发生实质变更，将随 App 更新在本页公布。

Privacy Policy

TokenBalance · Last updated: November 2026

The short version

TokenBalance has no server and collects no data. No account, no sign-up, no ads, no analytics SDK, no third-party tracking. Your API keys and balance data never leave your device.

What it does

TokenBalance is a local dashboard that gathers the balances, quota usage and spend trends of your AI provider accounts (DeepSeek, OpenAI, Zhipu, Kimi, MiniMax, StepFun, OpenRouter and others) into one screen.

Your data

  • API keys / tokens are stored in the on-device iOS Keychain. They are never uploaded and never synced to iCloud.
  • Account names, groups and balance history are stored in the app's local storage on your device.
  • Exchange rate preference is stored in local preferences.
  • The developer has no access to any of it. Deleting the app deletes everything.

Network requests

When you refresh (or enable auto-refresh), the app calls each provider's official API directly from your device using the key you entered, to read balances and usage. Requests go straight from your device to the provider — never through the developer or any intermediary server. Those requests are also governed by the provider's own privacy policy.

If you set a custom exchange rate, the app queries a public rate endpoint with no identifying information.

Permissions

  • Notifications: used only for local quota alerts you explicitly enable. Alerts are generated on-device, not via a push server.
  • The app requests no access to contacts, location, camera, microphone, health or photos.

Children

The app is not directed to children under 13 and does not knowingly collect information from them.

Changes

Material changes to this policy will be published on this page with an app update.

Support

TokenBalance 支持

把所有 AI 服务商的余额、配额和消耗收进一块屏。遇到问题先看下面，没解决就写信给我。

怎么添加一个服务

  • 点右下角 +，选服务类型（DeepSeek / OpenAI / 智谱 / Kimi / MiniMax / 阶跃星辰 / OpenRouter / 手动登记）。
  • 填一个名称（例如「主账号」），粘贴该服务商控制台里的 API Key。
  • 保存后回到首页，下拉刷新即可看到余额。

余额或用量抓不到

  • 确认 Key 有 读取账单 / 用量 的权限 —— 很多平台的普通推理 Key 只能调用模型，不能查余额。
  • OpenAI 需要的是带 billing 权限的会话 Token，或组织级 API Key；普通 sk- Key 查不到额度。
  • 智谱、MiniMax 的「配额窗口」需要额外的第二个 Key，在详情页的 Token 用量一节单独填。
  • 仍然失败时，详情页会显示具体错误码和原始返回，方便对照服务商文档。

配额告警怎么开

  • 进入服务详情页，设置「余额低于此金额提醒」或「配额剩余低于此 % 提醒」。
  • 首次设置会请求通知权限；允许后，每次刷新发现低于阈值就在本机发一条通知。
  • 通知在本机生成，不经过任何推送服务器。

数据存在哪里

API Key 存在本机 钥匙串，其余数据存在 App 的本地存储。没有服务器、没有账号、不上传、不同步 iCloud、无统计 SDK。卸载 App 即全部清除。

详见 隐私政策。

换手机怎么迁移

因为密钥刻意不做云同步，换机后需要在新设备上重新填一次 Key。这是隐私设计的代价，不是 Bug。

导出 CSV 打不开 / 乱码

导出文件是 UTF-8 带 BOM 的 CSV，Numbers、Excel、飞书表格都能直接打开。若出现乱码，用「导入为 UTF-8 文本」再试一次。

支持哪些平台

iPhone（iOS 17 及以上）与 iPad，支持深色模式、iPad 与折叠屏展开态的双列布局。界面提供简体中文、繁体中文、English、日本語。

Support (English)

Balances, quotas and spend for every AI provider — on one screen.

Adding a provider

Tap +, pick the provider type, name it, paste the API key from that provider's console, then pull to refresh on the dashboard.

A balance won't load

  • Most providers require a key with billing or usage read permission — a plain inference key usually can't read balances.
  • OpenAI needs a session token with billing access, or an organization API key. A regular sk- key cannot read credit grants.
  • Quota windows for Zhipu and MiniMax need a second key, entered separately under Token Usage in the detail screen.
  • The detail screen shows the exact error and raw response when a refresh fails.

Where is my data?

API keys live in the on-device Keychain; everything else is in local app storage. No server, no account, no upload, no iCloud sync, no analytics. Deleting the app removes all of it. See the privacy policy.

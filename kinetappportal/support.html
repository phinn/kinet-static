FAQ

How do I launch an app? / 怎么启动应用?

Press the global hotkey, type a few letters, hit Return. That's it — sub-second from thought to app.

Can I change the hotkey? / 能改热键吗?

Yes, pick any combination you like in settings.

Does AppPortal see my files? / 会读取我的文件吗?

No. AppPortal only reads the list of installed applications to search it. No file contents, no usage tracking, no network. See the Privacy Policy.

Why can't I find an app? / 为什么搜不到某个应用?

Apps in system-protected locations may need Full Disk Access: System Settings → Privacy & Security → Full Disk Access.

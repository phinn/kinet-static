Import: nothing happens when I pick a file

Pagebench accepts PDF files up to 50 MB and 2,000 pages. Password-protected PDFs are rejected — remove the password first. If the file still fails, it is likely damaged; try re-downloading it.

The pencil doesn't draw, only nothing happens

By default only Apple Pencil draws, so your palm never leaves stray marks. Turn on Settings → Ink → Draw with finger if you want finger or capacitive-touch inking.

My notes "disappeared" when I turned flipping off

They didn't. With flipping set to separate, the note pane stays on its page while the document moves. A badge ("Unlinked · note page N") tells you where you are, and Back to this page re-pairs them in one tap.

Can I link a note to a different page?

Yes — tap Back to this page while viewing the page you want, or use the link button. If the target page already has ink, the two note pages swap places so nothing is overwritten.

What does "orphan pages" mean in Settings?

If a PDF was replaced with a shorter version, notes on pages beyond the new end become "orphans". We keep them until you choose Clean up orphan pages, and the confirmation tells you how many contain ink before anything is removed.

Exported images

The share button exports the current document page and its note page as one full-resolution PNG with no watermark. It goes through the standard iOS share sheet — Photos, Mail, Messages, anywhere.

Deleting documents

Deleting a document removes its PDF and all of its note pages from your device. The confirmation dialog shows how many note pages will go before you confirm.
